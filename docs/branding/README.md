# Logo artwork

The [primary](wec-sim-python-primary.svg) and
[horizontal](wec-sim-python-horizontal.svg) SVGs are the original v17 artwork
supplied for this repository. Both are self-contained vector files.

The repository README displays
[a white-backed copy of the horizontal logo](wec-sim-python-horizontal-readme.svg)
so its dark navy lettering remains legible in GitHub's light and dark themes.
The source SVGs remain unchanged. Use the primary logo for square placements
and the horizontal logo for wide placements; keep their aspect ratios.
